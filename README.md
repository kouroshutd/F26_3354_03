# Campus Safety Incident & Emergency Accountability System

**Team 03 — CE/CS/SE 3354 Software Engineering — Fall 2026**

## Project Overview

This repository supports the Team 03 semester project for CE/CS/SE 3354.

The project explores a **Campus Safety Incident & Emergency Accountability System** designed to support campus safety workflows through an integrated software system.

The current project scope includes three related areas:

- Hazard reporting
- Safe Walk sessions
- Emergency accountability / check-in

The design goal is to treat these as parts of one system rather than independent applications. Events in one subsystem may affect another, such as a Safe Walk expiration creating an incident for review.
